# LichViet AI

Trợ lý lịch Việt tối giản: xem ngày, giải thích thuật ngữ và chủ động gợi ý dựa trên một engine có thể truy vết nguồn.

## Nguyên tắc
- Engine xác định kết quả; AI chỉ diễn giải.
- Lịch/Can Chi/tiết khí phải có kiểm thử đối chiếu nguồn.
- Quy tắc cát/hung phải ghi rõ nguồn và trạng thái xác minh.
- Không trình bày tín ngưỡng/truyền thống như sự thật khoa học.
